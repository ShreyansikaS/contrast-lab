# Contrast Lab

A WCAG 2.1 color contrast checker with live preview and CSS variable export.

**Live demo:** `https://YOUR-USERNAME.github.io/contrast-lab/` (after enabling GitHub Pages)

## Features
- Computes contrast ratio from relative luminance
- Reports AA, AAA, large-text, and UI component results
- Swap colors, copy ready-to-use CSS custom properties
- Light and dark theme, 44px touch targets, visible focus states

## Run locally
No build step. Open `index.html` in a browser.
